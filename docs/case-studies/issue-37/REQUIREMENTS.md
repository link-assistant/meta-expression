# Requirements

| ID    | Requirement                                                                                                          | Status | Evidence                                                                                                                  |
| ----- | -------------------------------------------------------------------------------------------------------------------- | ------ | ------------------------------------------------------------------------------------------------------------------------- |
| R37.1 | The Translate Report Issue link must not generate a URL that GitHub rejects as too long.                             | Done   | `createPageIssueReportUrl()` compacts oversized reports and `tests/issue-37.test.js` asserts a bounded URL.               |
| R37.2 | Original source-language text must always be included in the issue report.                                           | Done   | `Text` is a Translate compact-report essential section.                                                                   |
| R37.3 | Formalization of original language text must always be included.                                                     | Done   | Translate reports include `Formalized Input Markdown` from the live translate result.                                     |
| R37.4 | Target-language translation in formalized form must always be included.                                              | Done   | Translate compact reports retain `Markdown`, which now includes the linked `это` rule token.                              |
| R37.5 | Nonessential generated diagnostics may be omitted from compact issue URLs.                                           | Done   | `Links Notation`, `Translation CST`, and `Translation Steps` are omitted in compact Translate reports with a report note. |
| R37.6 | `is a` should be formalized as the exact Wiktionary compound when it exists, instead of separate `is` and `a` links. | Done   | Supported Wiktionary multi-word lookup maps `is a` to `is-a`; the test pins one formalized phrase.                        |
| R37.7 | Russian `это` generated by translation rules should be formalized/linked.                                            | Done   | Translation Markdown links the rule token to English Wiktionary's Russian `это` page.                                     |
| R37.8 | Gather issue, PR, related-code, and online research data under `docs/case-studies/issue-37`.                         | Done   | Raw captures live in `data/`; this README summarizes the findings.                                                        |
